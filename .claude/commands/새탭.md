argument-hint: <key> [label]

새 탭 `$ARGUMENTS`를 추가한다.

1. **`web/docs/protocols/새탭추가.md`를 읽고 그대로 따른다.**
2. 먼저 `cd web && node scripts/scaffold-tab.mjs $ARGUMENTS --dry` 로 스캐폴더가 **살아 있는지** 본다(정본 앵커가 바뀌면 첫 줄에서 죽는다 — 2026-09-02 까지 26일간 그랬다). 살아 있으면 `--dry` 없이 다시 돌려 tabs.ts 등록(TABS + 섹션)·registry 배선·feature 폴더·테스트 스텁을 결정적으로 생성한 뒤, 프로토콜의 나머지(구현·스타일·e2e·게이트)를 수행한다.
3. 스캐폴더가 없거나 죽어 있으면 **먼저 스크립트를 고치고**(정본에서 읽는 앵커를 맞춘다), 그래도 안 되면 프로토콜 1~6단계를 손으로 수행하되 그 사실을 원장에 적는다.
4. 끝에 `/게이트`로 검증하고 결과를 압축 보고한다.

key만 주어지면 label은 합리적 한글명을 제안하고 진행한다(사용자가 지정했으면 그대로).
