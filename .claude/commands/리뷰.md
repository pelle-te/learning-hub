---
description: feature/변경분을 web-reviewer로 다관점 리뷰
argument-hint: <feature 경로 또는 "diff">
---

`$ARGUMENTS`(특정 feature 폴더, 또는 "diff"면 현재 작업 변경분)를 리뷰한다.

1. 대상 파일 집합을 정한다(feature면 `web/src/features/<name>/**`, "diff"면 `git diff` 변경 파일).
2. **`web-reviewer` 서브에이전트를 관점별로 병렬 팬아웃**한다(한 메시지에 동시 실행):
   - 정확성/버그 · a11y · 레이어 경계(boundaries)/재사용 · 성능(리렌더·번들)
   각 에이전트에 대상 경로만 전달하고 **짧은 발견 목록**만 받는다(본문 덤프 금지).
3. 발견을 취합해 심각도순으로 정리하고, 각 건에 파일:라인 + 한 줄 근거 + 제안.
4. 사용자 승인 후에만 수정. 리뷰 자체는 읽기 전용.
