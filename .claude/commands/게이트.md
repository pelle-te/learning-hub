---
description: web 품질 게이트(verify+build+budget+e2e)를 돌리고 압축 리포트만 반환
argument-hint: (없음) | quick(verify만)
---

러닝허브 web 게이트를 실행하고 **압축 결과만** 보고한다(로그 덤프 금지).

1. `cd web && node scripts/gate.mjs $ARGUMENTS` 를 실행한다(있으면 머신리더블 요약 반환). 없으면 아래를 순차 실행:
   - `cd web && npm run verify` (typecheck + lint + format:check + test:coverage)
   - `$ARGUMENTS`가 `quick`이 아니면 `cd web && npm run build && npm run budget && npm run e2e` (번들 예산 포함 · 감사 #25)
2. 각 단계 **통과/실패 + 실패 시 첫 원인 한 줄**만 표로 보고. 전체 로그를 붙여넣지 말 것.
3. 실패가 있으면 원인 파일:라인을 짚고 고칠지 물어본다. 전부 녹색이면 "게이트 ✅"만.
