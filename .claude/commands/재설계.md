---
description: 탭 재설계 — today 재설계 사상을 해당 탭에 이식
argument-hint: <탭 key 또는 이름>
---

탭 `$ARGUMENTS`를 재설계한다.

1. **`web/docs/protocols/탭재설계.md`를 읽고 그 사상(단일 목적·상단 리드아웃·fill 프레임·온디맨드 세부)을 따른다.** today를 복붙하지 말 것.
2. 해당 탭의 현재 구현(`web/src/features/$ARGUMENTS/`)과 데이터를 파악해 "이 탭이 답하는 한 문장 질문"을 먼저 정의하고, 리드아웃·프레임을 설계해 사용자에게 제안한다.
3. 사용자가 못박은 제약이 있으면 그것이 사상보다 우선(명시 지시 임의변경 금지).
4. 큰 재설계면 설계→구현→검증을 서브에이전트로 분리한다.
5. 시각 변경이므로 `npm run e2e:update`로 스냅샷을 재생성하고 `/게이트` + `npm run build`.
