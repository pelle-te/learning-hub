`$ARGUMENTS`를 **평가루브릭으로 점수화**한다(게이트=통과/실패, 리뷰=결함발견과 다른 *채점*).

1. **`web/docs/평가루브릭.md`를 읽는다.** 대상 분기 판정: `features/<탭>`이면 A(7차원/35), `lib/<모듈>`이면 B(5차원/25), "diff"면 변경된 각 대상을 그 종류로.
2. **독립 채점(작업자≠검사자):** `web-evaluator` 서브에이전트를 **차원별로 병렬 팬아웃**(한 메시지에 동시 실행)한다 — 각 에이전트가 한 차원만 깊게 보면 다각도가 서로 오염되지 않는다. 대상이 여러 개면 (대상×차원)로.
   - 각 에이전트에 **대상 경로 + 루브릭 해당 차원 정의만** 전달. **증거 한 줄 필수**, 실행/측정 없이 판단한 정확성·성능·테스트 차원은 **N/A**로 돌려받는다(만점 금지).
   - 정확성·테스트 차원 채점 시 필요하면 `npm run test`/관련 테스트를, 성능은 `npm run budget`을 실제로 돌려 증거를 남긴다.
3. **집계:** 차원별 점수(N/A는 분모 제외)·총점 %·**약한 차원**을 표로. 자기 코드 자기채점 금지 원칙 재확인.
4. **추세 기록:** 결과를 `web/docs/평가기록.md` 형식으로 정리해 **추가할지 사용자에게 확인**(날짜·범위·커밋 SHA 포함). 최신이 위로.
5. **경고 명시:** 점수는 모델 판단이라 공유 맹점이 있음 — 추세 진단으로 쓰고 사람 교차검증을 권한다. 점수 위한 과적합 금지.

읽기 전용(코드 미수정). 약한 차원 보강은 별도 승인 후.
