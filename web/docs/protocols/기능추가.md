# 프로토콜: 기능(로직) 추가

> 트리거: "(기능) 추가 / 로직 붙여줘". 핵심 원칙 = **로직은 lib 순수함수로 먼저, 테스트로 고정한 뒤 UI에 배선**. 레이어 단방향(`app → features → components → {hooks, store} → lib`) 유지. ⚠ **`hooks` 를 빠뜨리지 마라** — 공유 훅이 사는 층이고, 없다고 적으면 그 코드가 `components` 나 `lib` 로 잘못 간다(V061 이 오버레이에서 고친 누락의 사본이 여기 있었다 · V100 · 2026-09-02). 집행자는 `eslint-plugin-boundaries` 이고 `web/eslint.config.js` 가 정본이다.

## 절차

1. **순수 로직 → `web/src/lib/`** React·DOM·전역 상태에 의존하지 않는 순수 함수로 작성(입력→출력). 스키마 검증은 `lib/schema`(zod).
   - **IO가 필요하면**: 백엔드(산출물·파이썬 도구·AI·볼트·Anki — ⛔ **「뉴스」가 여기 적혀 있었다**: `atlas_news` 는 P10 W4(2026-08-07)에 `survey/` 필러로 이사했고 이 저장소엔 그 커맨드가 없다 · V065)는 **Tauri 커맨드**를 부르는 `lib/api`(그 밑이 `lib/tauri.ts` 의 `invoke` 하나 · serve.js 는 4단계에서 삭제) · 앱 정본 저장은 `lib/db`(SQLite) · IDB 핸들·캐시는 `lib/idb` · 기기별 설정은 `lib/kv`.
   - ⚠ **이 데이터가 기기 간 동기화돼야 하나?** 그렇다면 `AppState`(→`lib/db/rows.ts` 매퍼가 자동 저장·아웃박스 수집) 또는 사용자 저작물이면 `lib/db/docs.ts` 를 경유해야 한다. `localStorage`·`useRuntime` 캐시에 직접 쓰면 **아웃박스가 안 훑어 영원히 동기화되지 않는다**(C-6 이 물린 조용한 유실). 동기화 불필요한 기기 로컬 값만 `lib/kv`·`useRuntime`.
   - 이유: 순수함수는 jsdom 없이 빠르게 단위 테스트되고, 레이어 최하단이라 어디서든 재사용 가능. 커버리지 게이트도 여기서 벌기 쉽다.

2. **단위 테스트 → `web/test/`** 경계·예외·회귀 케이스 포함. `npm run test`로 녹색.

3. **상태 배선 → `web/src/store/`** (필요 시)
   - 앱 데이터면 `useApp`, UI 설정이면 `useUI`, plan-무관 캐시면 `useRuntime`(§아키텍처 3). 서버 데이터 조회는 `store/queries`(react-query).
   - 영속이 필요하면 기존 flush/persist 계약을 따른다. ⚠ **"디스크 JSON 형태 불변"이 아니다**(2단계에서 정본이 SQLite 로 갔다) — 불변인 건 **`AppState` 형태와 내보내기 JSON(I1)** 이다. `AppState` 에 필드를 더하면 저장 계층은 알아서 따라온다(`ROW_SLICES` 밖 필드는 자동으로 `settings` 행이 된다). 매퍼를 손댈 일은 **그 슬라이스가 무제한으로 자랄 때**뿐이고, 그때 `lib/db/rows.ts` 에 행 슬라이스로 추가하고 `dbRows.test.ts` 왕복을 잠근다.

4. **UI 배선 → `web/src/features/<tab>/`** 컴포넌트에서 store/lib를 소비. 컴포넌트엔 계산 로직을 넣지 말고 lib 함수를 호출(테스트 가능성·재렌더 최적화).
   - React Compiler가 자동 메모하므로 수동 memo/useMemo 불필요. 단 Rules of React 준수(위반 시 컴파일러 bail → eslint-react-hooks가 잡음).

5. **게이트** `npm run verify` + 관련 있으면 `npm run e2e`. `/게이트`로 한 번에.
   ⛔ **`verify` 의 구성을 여기 손으로 적지 마라**(V100 · 2026-09-02) — 종전엔 «typecheck+lint+format+coverage» 넷이라 적혀 있었는데 실물은 그보다 많았다. 정본은 `web/package.json` 의 `verify` 이고, `web/test/docsFacts.test.ts` ④ 가 `CLAUDE.md` 의 열거 줄만 그것과 대조한다(그래서 열거는 거기 한 곳에만 둔다).

## 안티패턴 (하지 말 것)

- feature 컴포넌트 안에 복잡한 계산/파싱 인라인 → lib로 빼라(테스트 불가·재렌더마다 재계산).
- store에서 lib 아닌 상위 레이어 import → boundaries error.
- 새 localStorage 키 즉흥 추가 → 기존 persist 계약(useApp.flush 병합) 경유. **셸엔 localStorage 정본이 없다** — 직접 쓰면 그 값은 백업·이관에서 통째로 빠진다(`AnkiPanel` 이 실제로 그랬고 2단계-A4에서 `useUI` 로 흡수했다).
- 커버리지 떨구는 미검증 로직 병합 → 게이트가 막는다.
