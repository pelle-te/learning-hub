# 프로토콜: 새 탭 추가

> 트리거: "새 탭 추가 / (탭) 만들어줘". 탭은 **메타(shell)** 와 **구현(features)** 이 분리돼 있어 각 1줄 + feature 폴더로 완성된다.
> 결정적 스캐폴딩은 `/새탭 <key>`(=`node scripts/scaffold-tab.mjs`)가 아래 1~3을 생성한다. 손으로 할 때 체크리스트.
> ⚠ 스크립트는 `TabMeta`·`TabRole`·`RAIL_SECTIONS`·`ICON_PATHS` **정본에서 축을 읽으므로** 그 계약이 바뀌면 먼저 죽는다 —
> 착수 전 `--dry` 로 한 번 돌려 봐라. (V099 · 2026-09-02: 이 줄이 «자동 생성한다»라 적힌 채 스크립트는 **26일간 첫 줄에서 죽어 있었다** —
> N-14 가 지운 `GROUP_LABELS` 를 앵커로 찾고 있었다.)

## 절차

1. **메타 등록 — `web/src/shell/tabs.ts`** `TABS` 배열에 한 줄:

   ```ts
   { key: 'newtab', label: '새 탭', order: <빈 값>, role: 'destination'|'lens'|'view'|'object', icon: '<ICON_PATHS 키>' },
   ```
   - `order`는 **전역 표시 순서**(⌘K 목록)만 정한다. 레일 순서는 섹션이 적은 순서다.
   - ⚠ **`group` 은 없는 필드다**(N-14 · 2026-08-07). 묶음은 **`RAIL_SECTIONS`**(같은 파일)가 소유한다 — `destination`·`lens` 는 어느 섹션의 `tabs` 배열엔가 **반드시** key 를 적어야 한다(불변식 ③ · 안 적으면 레일 맨 끝 「섹션 미지정」으로 밀린다). 실물 섹션 키는 그 배열을 열어 세라(문서에 적으면 낡는다 — 여기 `plan|train|discover|settings` 라 적혀 있던 동안 실물은 `now·plan·know·system` 이었다).
   - **`role` 은 필수다**(D-4). `destination`=레일·`[ ]`링·`g`키에 선다 · `lens`=세그먼트·⌘K·딥링크로만 간다 · `view`=호스트 안의 뷰(`to` 필요 · 옛 `retired` 의 후신 · I048) · `object`=명사 주소(`route` 필요 · A-7). 옛 `hidden: true` 는 **부정으로 정의된 한 비트**라 소비처마다 해석이 갈렸고 그래서 사라졌다 — 쓰지 말 것.
   - ⚠ **`surface` 는 없는 필드다.** N-6(2026-07-26)이 학습/자료 두 표면을 해체했다. `collect` 그룹도 그때 함께 사라졌다.
   - 흡수 탭(호스트 안으로 접기)이면 `role:'view'` + `to`. `SUBTAB_GROUPS` 는 `RAIL_SECTIONS` 의 **파생**이라 거기에 「추가」할 수 없다.
   - 아이콘 키가 없으면 **`web/src/lib/iconPaths.ts`의 `ICON_PATHS`**에 SVG 추가(옛 `shell/icons.tsx` 는 없다). 오타는 typecheck가 잡는다(`IconName` 유니온).
   - ⚠ **`destination` 으로 낼 거면 세 의무가 더 붙는다** — 안 채우면 `verify` 가 불변식 셋으로 즉시 빨개진다(실측): ① `seq` 고유성(`g`키 첫 글자 충돌 시 `SEQ_OVERRIDE` 에 명시) ② `usePageChromeEffect` 의 `primary` 앵커 ③ 시그니처 표면(`ds-frame` 또는 `--bg-sig-*`/`--bg-hero-*` 베이크 면). 셋 다 사유 기반 면제 표가 `test/invariants.test.ts` 에 있다. 그래서 `/새탭` 의 기본 `role` 은 **`lens`** 다.

2. **구현 등록 — `web/src/features/registry.tsx`** `LOADERS`에 한 줄:

   ```ts
   newtab: () => import('./newtab/Newtab'),
   ```

3. **feature 폴더 — `web/src/features/newtab/`**
   - `Newtab.tsx` — `export default function Newtab()`. 데이터는 `store`(useApp·queries) / 순수로직은 `lib`에서. **상위 레이어(app) import 금지**(boundaries).
   - **스타일 = Tailwind 유틸리티 + 공유 `ds-*`(`styles/ds.css`)**. C-7 이후 `*.module.css` 는 0개다 — feature 스코프 CSS 파일을 만들지 말 것. 토큰 색은 tokenBridge 유틸(`text-txt`·`text-mut`·`text-acc`·`bg-panel` 등), 임의값(`w-[137px]`)은 금지. 규격은 `web/docs/디자인시스템.md`.
   - 빈 상태는 공용 `components/State`(`kind='empty'`) 사용 — **`next` 는 필수**이고, 행동이 없으면 `{ terminal: '왜 없는지' }` 를 쓴다.
     ⚠ 옛 `components/EmptyState` 는 E17 에서 `State` 로 흡수·**삭제**됐다(2026-07-31 감사에서 이 문서가 없는 파일을 지시하고 있었다). 4단계 판정은 `lib/artifactState.ts` 의 `classifyArtifact` 가 소유한다(판정=lib · 그리기=components).

4. **테스트 — `web/test/`** 최소 렌더 + 핵심 상호작용 vitest. 로직이 무거우면 먼저 `lib` 순수함수로 빼서 단위 테스트(→ `기능추가.md`).

5. **e2e 스냅샷 — `web/e2e/`** 시각 스냅샷이 있으면 `npm run e2e:update`로 **신규** 스냅샷 생성(기본 `changed`는 신규를 안 박음 — CLAUDE.md 함정 참고).

6. **게이트** `/게이트`(정본은 `web/scripts/gate.mjs` 의 `ALL` — 단계를 여기 베끼지 않는다). `verify`·`e2e` 만 녹색인 것은 완료가 아니다(CLAUDE.md). 필요 시 `npm run build`.

## 검증 포인트

- 나브·⌘K 팔레트·`g`+키 단축키가 새 탭을 자동 인식하는가(tabs.ts 단일 순회라 자동).
- boundaries 위반 없는가(feature가 app/다른 feature를 import하지 않음 — lint가 잡음).
- 라우트 딥링크(`/newtab`)·프리페치(hover) 동작.
