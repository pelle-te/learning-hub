# 러닝 허브 — 디자인 시스템 SSOT

> 토큰·테마·액센트·컴포넌트 규격의 단일 진리. 새 스타일은 **여기 토큰을 쓰고**, **Tailwind 유틸리티 + 공유 `ds-*`(`styles/ds.css`)** 로 조립한다(C-7 이후 `*.module.css` 는 0개 · 아래 §4). Tailwind 규약 3가지의 SSOT 는 `src/phone/phone.css` 머리주석, 남은 CSS 의 존재 이유는 `클라우드전환-설계.md` §15-15 표.

## 0. 시각 언어 — 에디토리얼 다크

다른 문서가 "**에디토리얼 다크 사상**"으로 참조하는 5원칙. (원본 리디자인 설계도는 실행 완료 후 삭제됐고, 그 유일한 생존 자산이 이 절이다. 레퍼런스: Lando Norris·Halo Lab Medtech — 다크·단일 네온·에디토리얼·발광.)

1. **순백 검정 + 단일 네온** — 캔버스는 딥 블랙, 액센트는 단 하나(기본 라임). 다색 글래스 금지.
2. **고밀도 HUD + 디스플레이 앵커** — 본문은 촘촘한 계기판이고, 디스플레이 활자(44~96px)는 **리드아웃과 시그니처에만** 쓴다. 화면당 앵커 1개.
3. **시그니처 비주얼 = 페이지마다 하나** — 카드 속 차트가 아니라 그 페이지 기능을 압축한 _맞춤 발광 오브젝트_(오늘=트랙·숙달도=지식맵).
4. **둥근 글래스 카드 폐기** — 검정 위 타이포 + 얇은 헤어라인 + 정렬 + 노치 HUD 프레임. 여백은 "빈 카드"가 아니라 의도된 캔버스.
5. **강·약 위계 + 라이브감** — 단일 포커스(가장 큼) → 나머지 작게. 카운트업·드로우·펄스·"지금" 실시간 마커로 살아있게.

> ⚠ **원칙 ②는 2026-07-29 에 다시 쓰였다**(옛 문구: _"에디토리얼 타이포가 주인공 — 디스플레이 스케일(48~84px)·회전 스파인·네온 숫자. 타입을 그래픽으로 쓴다"_). 실측이 그 선언을 거짓으로 만들었기 때문이다:
>
> - 앱 텍스트의 **87%가 10~13px**(`text-sm` 175 + `xs` 166 + `2xs` 91 + `md` 77 = 509회), 15px 초과는 **26회(4.4%)**.
> - 중량은 **98%가 600 이상**(`bold` 180 + `extrabold` 153 + `semibold` 79 + `black` 20 = 442) vs `medium` 7 + `normal` 3.
> - 위계를 실제로 운반하는 것은 크기가 아니라 **디밍**이다 — `text-mut` 392 + `ds-muted` 168 = **560** vs `text-txt` 171 + `text-ink` 13 = 184.
>
> 즉 이 앱의 실제 시각 언어는 에디토리얼이 아니라 **고밀도 HUD** 였고, 선언만 남겨 두면 새 화면마다 두 언어가 섞인다. 선택지는 둘이었다 — 밀도 25~35%를 버리고 3단 사다리(13/21/34)로 가거나, 선언을 사실에 맞추거나. **후자를 택했다**: `alloc` 매트릭스·`schedule` 주뷰처럼 **밀도가 곧 기능**인 fill 대시보드가 16개이고, 그것들을 살리려면 어차피 "표" 예외를 파야 하는데 예외를 파는 순간 3단이라는 명제가 스스로 무너진다.
>
> 뒤집힌 것은 **범위**이지 야심이 아니다. 디스플레이 활자는 여전히 쓰되 **자리가 정해졌다**: 상단 리드아웃 `primary`(44px · `usePageChrome`)와 페이지 시그니처. 그 둘 밖에서 48px+ 를 세우려면 그건 새 앵커를 만드는 것이므로 원칙 ⑤(단일 포커스)와 충돌하는지 먼저 물어야 한다.

> 재설계 _절차_(단일목적·상단 리드아웃·fill 프레임·온디맨드 세부)의 정본은 `protocols/탭재설계.md`. 토큰·컴포넌트 규격은 아래 §1~.

## 1. 토큰 (`src/styles/tokens.css`)

`:root`에 정의, `<html data-theme>`로 통째 스왑. `:root` 기본=다크(JS 부팅 전에도 다크 렌더 → FOUC 방지).

| 그룹          | 변수                                                                                 |
| ------------- | ------------------------------------------------------------------------------------ |
| 배경/패널     | `--bg` `--bg2` `--panel` `--panel2`                                                  |
| 라인/헤어라인 | `--line` `--line-soft`(=`--line2`) `--hairline`                                      |
| 텍스트        | `--txt`(=`--ink`) `--mut`                                                            |
| 액센트        | `--acc` `--acc2` `--on-acc` · 파생 `--acc-soft`(14%) `--acc-glow`(40%) `--glow`(55%) |
| 상태          | `--warn` `--bad` `--good`                                                            |
| 반경          | `--r`(12px) `--r-lg` `--r-md` `--r-sm`                                               |
| 그림자/이징   | `--shadow-{sm,md,lg}` `--ease`(cubic-bezier(.22,.61,.36,1))                          |

- **액센트 파생 규칙:** `--acc` 하나만 바꾸면 soft/glow/glow가 color-mix로 따라온다. 액센트 노브의 근거.
- 색/반경/그림자는 테마별 재정의, 이징/반경 같은 테마 무관 값은 `:root`에서만.

## 2. 테마 · 액센트

- **테마:** `data-theme='dark'`(기본) / `'light'`. `ThemeProvider`가 토글. 세피아 폐기, 2테마.
- **액센트 노브(4색):** `violet` · `lime` · `cyan` · `amber` (`src/lib/uiState.ts` `AccentSchema`). `<html data-accent>` 프리셋 ↔ 1:1. **기본 = `lime`**(확정). `useUI.setAccent`로 변경, 즉시 persist.

## 3. 과목 색 — OKLCH 생성 (`src/lib/utils.ts`)

```ts
const SUBJECT_L = 0.72; // OKLCH 명도(두 테마 공용 hex)
const SUBJECT_C = 0.15; // OKLCH 채도(게멋 밖 hue 는 oklchToHex 가 축소해 맞춤)
// colorForId(id) = oklchToHex(SUBJECT_L, SUBJECT_C, hash(id) % 360) → hex
```

- **과목 색은 저장값이 아니라 파생물** — **항목 id 해시 → 색상환 각도(hue)**, L·C 고정으로 `colorForId(item.id)`가 유도(2026-07-24 에 옛 8색 라임 배열을 OKLCH 생성으로 교체). 출력은 hex 라 모든 소비처가 그대로 받는다. 수동 색 선택 UI 없음.
- ⚠ **8색 한계가 없다** — 색상환 전체(0~359°)에 흩어져 과목이 5개든 50개든 서로 또렷이 구분된다. 옛 8색 배열은 5과목만 돼도 두 과목이 같은 색일 확률이 ~80%였다(생일 문제).
- ⚠ **파생 키가 id 인 이유**: 인덱스는 *위치*라 삭제·재정렬 때 뒤 과목 색이 밀렸다. id 는 *정체성*이라 불변, 파생이 1곳 — **순서를 바꿔도 과목 색은 그대로.**
- **두 노브(`SUBJECT_L`·`SUBJECT_C`) 교체 → 전 탭·모든 저장 데이터가 다음 부팅에 갱신.** 임의 색 하드코딩·저장값 취급 금지(절대규칙 3 — 원칙은 그대로, '무엇으로부터 파생하는가'만 배열→OKLCH).

## 4. 스타일 층 (C-7 Tailwind 전환 완료 · `*.module.css` = 0)

스타일은 **세 자리** 중 하나다. `*.module.css` 는 없다(C-7 에서 전량 제거).

| 층                          | 무엇                                                                   | 언제 쓰나                                        |
| --------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------ |
| **① JSX Tailwind 유틸리티** | `className="flex gap-4 p-4 text-txt"` 처럼 인라인 유틸리티             | 대부분의 레이아웃·간격·타이포                    |
| **② 공유 `ds-*`**           | `styles/ds.css` 의 전역 클래스(`ds-card`·`ds-pill`·`ds-bar`·`ds-kpi`…) | 룩을 여러 곳이 공유할 때 — `className="ds-card"` |
| **③ 앱 리셋·크롬**          | `styles/global/`(리셋·base·앱 셸 크롬)                                 | 앱 전역 프리미티브(직접 새로 만들 일은 드물다)   |

- ⚠ **`ds-*` 는 CSS Module 이 아니라 생 전역 클래스다** — `import styles` 없이 문자열로 쓴다(`className="ds-card ds-pill"`). 옛 `ds.module.css`/`composes` 관용구는 C-7 에서 사라졌다.
- ⚠ **레이어가 계약이다**: `@layer base, components, theme, utilities`. `global/{base}.css`=base · `global/features.css`=components · **`ds.css`·`motion.css` 는 언레이어드(유틸리티를 이긴다 → 덮으려면 `!`)**. 순서는 최초 등장 순이라 `main.tsx` 의 `global/index.css`→`tw.css`→`ds.css` import 순서가 그 계약이다(CLAUDE.md).
- ⚠ **버튼 hover 장식엔 `enabled:`** — 유틸리티는 전역의 `:not(:disabled)` 가드를 상속하지 않는다(비활성 버튼이 hover 에서 밝아진 실사고).
- ⚠ **표면 레지스터는 넷이다**(E28 · 2026-07-30 · `ds-card` 은퇴의 완성): `ds-canvas`(상자 없음) ·
  `ds-rule`(위 헤어라인 한 줄) · `ds-well`(눌린 면 · 단독 객체) · **`ds-frame`(노치 HUD · 모서리
  브래킷)**. 원칙 ④ 문장은 _"얇은 헤어라인 + **노치 HUD 프레임**"_ 인데 앞쪽 세 개가 앞 절반이고
  `ds-frame` 이 **뒤 절반**이다 — 이름만 있고 코드엔 없던 형태를 신설했다.
  - `ds-frame` 은 **한 화면에 하나**(원칙 ③ 시그니처). 여러 개 쓰면 화면이 사이파이 장식이 된다.
  - 색은 `--frame-line` 이고 **테마별로 세기가 다르다**(다크 55% / 라이트 88%) — 다크 값을 라이트에
    쓰면 흰 패널에서 사라진다(E4 가 헤어라인에서 물린 것과 같은 부류 · 실렌더로 확인).
  - ⚠ 브래킷은 **`::after`** 다. `ds-hairline` 이 `::before` 를 쓰고 시그니처 표면은 거의 항상 그
    둘을 함께 달므로, `::before` 로 만들면 **한쪽이 조용히 사라진다**(에러·경고 0 · 실렌더로 잡았다).
- 임의값(`w-[137px]`) 금지 · 색은 tokenBridge 유틸(`text-txt`·`text-mut`·`text-acc`·`bg-panel`…)로. 집행자는 **`eslint-plugin-better-tailwindcss`**(feature 를 옮길 때마다 `files` 목록이 넓어진다).
- feature 안에서 노드 클래스가 여럿이면 **모듈 상단 상수 맵**으로 SSOT 화한다(`features/today/FlowRail.tsx` 의 `N` 맵이 표본 — `*.module.css` 를 대체한 관용구).
- 카드 등장 모션은 마운트 1회(스태거), reduced-motion 은 `motion.css` 전역 백스톱이 처리. 성공하지 않은 화면(빈·로딩·에러)은 공용 `components/State` **하나**가 그린다(E17 · `next` 필수 · 판정은 `lib/artifactState.classifyArtifact`). ⚠ 옛 `EmptyState`·`ArtifactError` 는 삭제됐다.
- ⚠ **모션은 어휘 다섯 마디 + 시간 사다리로 닫혀 있다**(E24 · 2026-07-30). 키프레임 32종 → 20종, 길이 리터럴 15종 → 토큰 8종.
  - 어휘 SSOT = `lib/motion.ts` 머리주석 (**enter · commit · live · transit · draw**) · 키프레임 SSOT = `styles/tw.css`.
  - **`draw` 가 다섯째다** — 값이 자기 크기까지 자라는 것(링 arc·막대·진행 채움). 이 어휘가 없던 동안 700·1000ms 가 사다리 밖에 표류했다.
  - 길이는 **토큰만** 쓴다: `--dur-fast|--dur|--dur-slow`(1회) · `--dur-cele`(축하) · `--draw`(값 그리기) · `--tempo-fast|--tempo|--tempo-slow`(무한 주기) · `--stagger`(한 칸). transition 은 `duration-fast|base|slow|draw` 유틸.
  - 새 움직임을 들일 때: **축(메커니즘)이 다르면 새 이름, 같은 축의 크기 차이면 노브**(`--rise-y`·`--pulse-r` 등 · 노브 묶음은 `@utility`). 차이가 2% 이하면 드리프트다.
  - 집행자는 **불변식 ⑥**(`test/invariants.test.ts`) — 어휘 밖 키프레임 이름·시간 리터럴·`duration-<이름>` 브리지 누락을 전부 게이트로 막는다. 정지 프레임 스냅샷은 이 층을 원리적으로 못 보므로(`e2e/motion.spec.ts` 머리주석) 주석에 맡기지 않는다.

### 4-1. `ds-*`(styles/ds.css) ↔ `components/ui/*` — 둘의 관계

두 층이 **병존**한다.

| 층                | 무엇                                                  | 언제 쓰나                                                   |
| ----------------- | ----------------------------------------------------- | ----------------------------------------------------------- |
| `ds-*`(ds.css)    | 스타일만 있는 공유 전역 클래스(`ds-card`·`ds-pill`·…) | 대부분. 마크업이 제각각이고 룩만 공유하면 될 때             |
| `components/ui/*` | 스타일 **+ 마크업/동작**을 함께 갖는 컴포넌트         | 구조가 반복될 때(`<Card title>`·`<Kpi>`·`<NumberField>` 등) |

**철칙: 룩의 SSOT 는 언제나 `ds-*` 다.** `components/ui` 가 같은 룩을 쓰면 값을 베끼지 말고 그 컴포넌트가 `className="ds-card"` 를 두르거나 `@apply` 로 가져온다(옛 `composes` 는 CSS Module 전용이라 없어졌다).

## 5. 규칙 요약

- 새 색·간격은 토큰 참조. 새 전역 클래스·`*.module.css` 신설 ✗ → Tailwind 유틸리티 + `ds-*` 조합.
- **룩을 베끼지 말고 `ds-*` 재사용** — 값 복제는 드리프트의 씨앗(§4-1).
- 생 hex ✗ · 브레이크포인트는 560/700/900 3종만 — `npm run lint:css`(stylelint)가 강제. Tailwind 클래스 규약은 `eslint-plugin-better-tailwindcss`.
- 발광/모션은 `fxLite` 토글·reduced-motion 백스톱 존중.
- 시각 변경 후 스냅샷 재생성 — ⚠ `npm run e2e:update`(=`--update-snapshots=all --workers=1`)는 **화면이 보이는 스냅샷 전부**를 다시 굽는다. 일부만 재생성하려면 `-g <제목>` 으로 좁히고 `=all` 유지(CLAUDE.md e2e 함정). 이어 `npm run build`.
