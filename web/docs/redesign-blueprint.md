# 러닝 허브 — 에디토리얼 다크 리디자인 설계도

> 출처 컨셉: 데모 v6 (`docs/_demo_today_v6.html`). 레퍼런스: Lando Norris(다크·단일 네온·에디토리얼·발광 트랙), Halo Lab Medtech(에디토리얼 헤드라인·시그니처 비주얼·밀도).
> 원칙: **UX/UI = 기능.** 모든 요소는 읽히고 즉시 행동으로 이어져야 한다.

---

## 0. 디자인 원칙 (5)

1. **순백 검정 + 단일 네온** — 캔버스는 딥 블랙, 액센트는 단 하나(기본 라임 `#b6f23a`, 대안 인디고/시안). 다색 글래스 금지.
2. **에디토리얼 타이포가 주인공** — 디스플레이 스케일(48~84px), 회전 스파인, 네온 숫자. 타입을 그래픽으로 쓴다.
3. **시그니처 비주얼 = 페이지마다 하나** — 카드 속 차트가 아니라, 그 페이지 기능을 압축한 _맞춤 발광 오브젝트_(오늘=트랙, 숙달도=지식맵 …).
4. **둥근 글래스 카드 폐기** — 콘텐츠는 검정 위에 타이포 + 얇은 헤어라인 + 정렬 + 노치 HUD 프레임으로 조직. 여백은 "빈 카드"가 아니라 의도된 캔버스.
5. **강·약 위계 + 라이브감** — 단일 포커스(가장 큼) → 나머지 작게. 카운트업·드로우·펄스·"지금" 실시간 마커로 살아있게.

## 1. 공유 디자인 시스템 (셸)

### 1-1. 토큰 (`tokens.css` 확장 / 신규 다크 권위값)

- `--bg #050506`, `--ink #f4f5f7`, `--mut #767a85`
- `--acc #9b8cff`(인디고-바이올렛 네온, ~~확정~~ → **이후 라임 기본으로 재확정** — shipped 기본은 `data-accent="lime"`, 현행 SSOT는 `디자인시스템.md`), `--glow rgba(155,140,255,.55)`
- `--line .13α`, `--line2 .07α` (헤어라인 2단계)
- 타이포: `--fs-display 84` / `--fs-hero 60` / `--fs-xl 46` / `--fs-l 30` / 본문 15 / 라벨 10~11(대문자·트래킹 0.16em). 전부 세미볼드↑(다크에서 얇은 폰트 금지).
- 모션: `--ease`, 표준 keyframes(rise/seg/draw/pulse/countUp).

### 1-2. 셸 컴포넌트 (신규 `app/` · `components/hud/`)

- **RailSidebar** — 60px 아이콘 레일, hover 시 펼침(라벨). 활성=네온 글로우. (현 `Nav` 대체)
- **TopBar** — 워드마크(스택) + **컨텍스트 리드아웃**(페이지별 핵심 지표 2~3개를 Lando식 큰 숫자로) + ⌘K + **주 액션 버튼**(네온 필).
- **HudFrame** — 노치 코너(clip-path) 보더 프레임. 페이지 본문 컨테이너.
- **SectionSpine** — 좌측 세로 회전 라벨(에디토리얼). 한글은 _똑바로_(vertical-rl, rotate 없음), 보조용으로만.
- **Readout / Stat** — 라벨(작은 대문자) + 큰 숫자(네온/화이트). 카운트업.
- **NeonTrack** — 발광 타임라인(세그먼트+주석+"지금" 노드). 오늘/스케줄 공용.
- **NeonChart** — area/bar draw 애니메이션 SVG. 단색 네온.
- **DataTable / LogRow** — 헤어라인 행, 현재/활성=네온. (스케줄/항목/기록 공용)
- **Segmented** — 흡수 탭 전환(섹션). 기존 SubTabs를 HUD 스타일로.

### 1-3. 셸 레이아웃 변경 (큰 작업)

- `.wrap` 중앙 1200px 박스 폐기 → **풀폭 그리드 `[60px 레일 | 1fr 본문]`**, 본문 100vh.
- `App.tsx`: 상단 탭 나브 → 레일 사이드바 + TopBar + HudFrame 라우트.
- 라우트·⌘K·g단축키·뷰트랜지션 계약 유지(흡수 탭은 Segmented로).

### 1-4. 결정 사항 — ✅ 확정 (2026-06-29)

- ~~**액센트 = 인디고-바이올렛 네온**~~ → 역사 컨셉 표기 — shipped 기본은 **라임**(uiState 기본 · `디자인시스템.md`가 현행 SSOT). 바이올렛은 tokens.css :root 원값으로만 잔존, 부팅 후 data-accent 프리셋이 덮는다.
- **테마 = 다크 기본 + 라이트 에디토리얼 1종. 세피아 폐기.** 토큰은 이 두 테마만 정의.
- **접근성**(이식 시 준수): 네온/딥블랙 대비 WCAG 검증, muted 텍스트 최저 대비 상향, 포커스 링.

## 2. 페이지별 시그니처 설계 (탭 = 각 기능 정체성)

각 페이지 = **공유 셸 + 고유 시그니처 비주얼 + 기능 매핑**. 데이터 소스는 기존 store/selector/`/api` 그대로.

### 🎯 오늘 (today) — _데모 v6 그대로_

- **시그니처**: 발광 "오늘의 트랙"(하루 타임라인) + 회전 "지금 과목" 스파인.
- **레이아웃**: TopBar 리드아웃(진행률·연속·마감) / HudFrame[스파인 | 스탯 | 트랙+다음콜아웃+주간미니트랙 | 오늘블록 테이블] / 하단 라인 스트립(마감·Anki·보충).
- **기능 매핑**: `useSchedule().days`+`layoutDay` → 트랙·블록 / `studyStreak`·`isDone` → 진행·연속 / `openBacklog` → 보충 / `_ankiLive` → Anki / 의식·흐름가이드 → "＋" 펼침.
- **모션**: 트랙 세그 stagger, "지금" 펄스, 숫자 카운트업, 블록 체크 시 마이크로 축하.

### 📅 주간 스케줄 (schedule) ＋ 가용시간·일과 ＋ 졸업 (Segmented 흡수)

- **시그니처**: **네온 위크-그리드** — 7일을 가로 트랙 7줄로 쌓은 발광 보드(오늘 트랙의 주(週) 확장). 각 줄=요일, 세그=블록, "지금" 마커, 마감=네온 플래그.
- **섹션(Segmented)**:
  - **스케줄**: 위크-그리드 + 요일 클릭 → 그날 상세 트랙. (`scheduleView`/`useSchedule`)
  - **가용시간·일과**: 24h **링/데이 템플릿 에디터**(수면·식사·수업 빼면 공부창 자동) HUD. (`routine`/`freeWindows`)
  - **졸업 계획**: **시즌 로드맵** — 학기를 가로 진행 트랙으로(Lando 시즌 캘린더 결), 학점 진행 네온 바. (`degree`)
- **기능**: 주/일 전환, 가용시간 인라인 편집, 마감 카운트다운.

### 📄 학습 항목 (items)

- **시그니처**: **로스터(Roster)** — 과목을 큰 에디토리얼 행으로(레이싱 그리드 결). 행: 과목명(대형)·색·챕터 진행 네온 바·주당 h·마감.
- **인터랙션**: 행 클릭 → **챕터 에디터**(HUD 테이블, 드래그 정렬). 볼트에서 불러오기 CTA.
- **기능**: `items` CRUD, 챕터 hours/done, weeklyHours/dailyMin/deadline. (`makeItem`, ChapterEditor)

### 🔗 연동 현황 (integrations)

- **시그니처**: **텔레메트리 콘솔** — serve.js/볼트/Anki **연결 상태를 라이브 리드아웃**(● ONLINE/OFFLINE), 동기화 활동, 볼트 인덱스 통계, Anki 덱 분해를 네온 바로. (시스템 폴더 `/api` 연동의 "조종석".)
- **기능**: VaultPanel(인덱스·과목 불러오기), AnkiPanel(라이브 due·카드 내보내기). 오프라인 폴백 = "SIGNAL LOST" HUD.

### 📓 학습 기록 (journal) ＋ 주간 리뷰 (Segmented 흡수)

- **시그니처**: **로그 스트림** — 기록을 검정 위 에디토리얼 타임라인으로. 3문장 요약=얇은 행, **CBMS=진단 칩 행**(C/B/M/S/T 색), 보충=네온 플래그.
- **섹션**: 기록(일별 입력·요약·CBMS·보충) / **주간 디브리프**(review) — 한 주를 "레이스 리포트"처럼 점검·체크. (`summaries`/`cbms`/`backlog`/`weekly`)
- **기능**: prefill(오늘 블록→기록), CBMS 분류, 보충 회수.

### 📊 통계 ＋ 🗺 숙달도 지도 (stats/mastery, Segmented)

- **시그니처(통계)**: **데이터 보드** — 주간 시간 area, 과목별 진행 바, 연속 그래프(전부 단색 네온 draw).
- **시그니처(숙달도)**: **발광 지식맵** — `/api` 지식상태를 과목/챕터 노드로, 숙달도 p→글로우 강도·색(`masteryColor` hsl). 히트맵/그래프. ← 강력한 시그니처 비주얼.
- **기능**: KPI(capUsed/Total·weekHours), itemStat 표, mastery API 폴백(셋업 안내).

### ⚙ 시스템 제어판 (control, 숨김·⌘K)

- **시그니처**: **옵스 콘솔** — 터미널/HUD. serve.js 상태, 인덱스·린트·벌트DB build 실행 버튼, 로그 스트림. (HUD 미학과 완벽 일치 — 레이싱 텔레메트리.)

### ⚙ 설정 (settings, 숨김)

- 미니멀 HUD 폼: moduleLen·reviewRatio·**테마/액센트 노브**·데이터 내보내기/가져오기/초기화.

## 3. 구현 로드맵 (React 이식 · 단계적)

**Phase A — 디자인 시스템 기반** (셸 교체, 가장 큰 변경)

1. 토큰 재정의(다크 권위값 + 액센트 노브) — `tokens.css`.
2. HUD 셸 컴포넌트 신설 — RailSidebar·TopBar·HudFrame·Readout·NeonTrack·NeonChart·DataTable·Segmented.
3. `App.tsx` 레이아웃 풀폭 셸로 교체(중앙 박스 폐기). 라우트/⌘K/단축키/뷰트랜지션 유지.
4. 검증: 타입·lint·테스트·e2e 스냅샷 재생성.

**Phase B — 오늘 페이지** (검증된 데모) 5. TodayHero/Track/Blocks를 실데이터로(useSchedule·layoutDay·studyStreak). NeonTrack 컴포넌트화. 모션·실시간 마커.

**Phase C — 페이지별 시그니처** (한 번에 하나, 각 PR) 6. 스케줄(위크-그리드 + routine·degree 섹션) → 7. 학습 항목(로스터+챕터에디터) → 8. 연동(텔레메트리) → 9. 기록(로그+리뷰) → 10. 통계+숙달도(보드+지식맵) → 11. 제어판/설정(콘솔/폼).

**Phase D — 마감 (UX=기능 끝마무리)** 12. **빈 상태 설계** — 각 페이지 데이터 적을 때도 의도적으로 보이게(빈 깡통 금지). 13. **인터랙션** — 호버 디테일·상태 전이·탭 뷰트랜지션·키보드. 14. **접근성** — 네온 대비 WCAG, 포커스 링, 모션 줄이기(prefers-reduced-motion). 15. **반응형** — 레일 접힘·프레임 스택(모바일은 하단 탭/단일 컬럼). 16. 테스트 보강 + 비주얼 베이스라인 재생성 + 커밋.

## 4. 리스크 · 메모

- **셸 교체 = 전 탭·테스트·e2e 영향**. Phase A에서 한 번에 흔들리니 스냅샷 재생성 전제.
- **밀도 vs 빈 상태**: 데모는 목업이라 꽉 참. 실데이터(특히 신규 사용자) 기준 빈 상태를 1급으로.
- **접근성**: 네온/딥블랙 muted 텍스트는 대비 미달 위험 — 토큰 단계에서 검증.
- **성능**: 글로우/blur/애니메이션 비용 — 큰 리스트·모바일에서 절제.
- **한글 세로 타이포**: 시그니처 스파인에만 _똑바로_ 사용, 남용 금지.
- **테마 범위 결정**(§1-4) 먼저 확정해야 토큰·전 페이지가 안 흔들림.
