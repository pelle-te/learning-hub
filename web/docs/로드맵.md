# 로드맵 / 백로그 — "다음 뭐"의 단일 출처

**목적:** 개선·확장·기술부채·아이디어를 한 곳에 모아 **가치/노력으로 랭크**한 살아있는 백로그. 흩어진 "나중에"(결정로그 열린 결정·평가기록 보류·리뷰 비차단 지적)를 여기로 수렴한다.

> **항목이 들어오는 경로**
>
> - `/개선` — 향상 발굴 · `/아이디어` — 확장 구상 · `/평가` 보류 차원 · `/리뷰` 비차단 지적 · 사용자
> - 채점·랭크는 `개선루브릭.md`(가치·노력·정합성·리스크). 티어: **Now**(가치高·노력低) · **Next**(가치高·노력高, 쪼갬) · **Later**(가치低·노력低, 틈날 때) · **Someday**(가치低·노력高/정합낮음).
> - ⚠ 표 뒤 설명은 빈 줄+불릿으로(prettier 흡수 방지).

## 진행 규칙

- 착수 전 `개선루브릭.md`로 재확인(오래된 항목은 가치·정합성이 바뀌었을 수 있다).
- 착수 = 해당 protocol(기능추가·재설계 등) + 게이트. 완료하면 아래 아카이브로 이동(날짜·커밋).
- Someday/드롭도 **이유와 함께 남긴다**(다시 떠오를 때 재논의 근거).
