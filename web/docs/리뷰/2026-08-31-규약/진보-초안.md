## 2. ⭐ 탈락 프레이밍 — **저 표본 옆에 놓으면 무엇이 먼저 아마추어처럼 보이나**

> 이 저장소의 문서는 **읽는 품질이 표본급이다** — 근거·반례·「왜 이렇게 고쳤나」가 실제로 있고,
> 「손으로 베낀 목록은 표류한다」를 **명문화**까지 했다. 아마추어처럼 보이는 곳은 문장이 아니라
> **그 규율이 자기 문서에는 적용되지 않았다는 사실**이다:
>
> `CLAUDE.md:258` 이 «파이썬 도구 **7종**»이라 적고 **네 줄 뒤 262줄이 «7→5»** 라 적는다.
> 한 화면 안에서 자기와 모순인데 **어떤 게이트도 빨개지지 않는다.**
> 표본 셋은 전부 이 부류를 **기계가 막는다**(K8s=재생성 대조 · Rust=컴파일 · Django=CI 필수).
> 우리는 그것을 **경고문으로** 막으려 했고, 경고문 바로 옆에서 실패했다.

## 3. 네 칸 해부 — ⓓ=**없음** 먼저

### ⓐ~ⓔ ① **문서의 사실 주장을 「생성」하거나 「대조」한다** (K8s `verify-generated-docs.sh`)

- ⓐ **왜 의무인가**: 문서와 소스가 **같은 사실**을 말할 때 둘 중 하나는 파생이어야 한다.
  K8s 는 문서를 **소스에서 생성**하고 CI 가 재생성 결과와 커밋본을 대조해 **다르면 실패**시킨다
  (`kube::verify::generated "Generated docs need to be updated"`).
- ⓑ **없으면 나는 사고**: 정확히 우리가 오늘 실측한 것 — `TOOLS.len()==5` 인데 문서는 7종,
  `verify` 10단계인데 문서는 8단계, 래칫 3개인데 문서는 2개. 인수인계받은 사람은 **코드를 안 읽고
  믿는다**(그게 문서의 존재 이유이므로).
- ⓒ **대가**: 생성된 문서는 **사람이 손으로 못 고친다**. 톤·설명·「왜」가 들어갈 자리가 사라져,
  K8s 의 생성 docs 는 실제로 **레퍼런스만** 있고 서사가 없다. 우리 문서의 강점(근거·반례)은
  전량 생성으로 가면 죽는다.
- ⓓ **우리 현재: 없음** `[측정]` — `.md` 를 읽는 집행자 0.
- ⓔ **우리 규모의 최소형**: 전량 생성이 아니라 **「대조 가능한 주장에만 표식」**.
  `<!-- 실측: TOOLS -->` 같은 마커를 단 줄만 테스트가 검사한다. 마커 없는 산문은 손으로 쓰는
  그대로 둔다 — 서사를 죽이지 않으면서 «수와 목록»만 잠근다. `test/workspacePaths.test.ts`(V040)가
  이미 같은 형태로 **화면의 경로**를 잠그고 있다: 그 관용구를 **문서**로 넓히는 것이다.

### ② **문서의 코드블록·명령이 실행된다** (Rust `cargo test --doc`)

- ⓐ 예제가 컴파일·실행되므로 **낡을 수 없다** — 낡으면 테스트가 깨진다.
- ⓑ 없으면: 안내가 지시하는 명령이 **존재하지 않아도 아무도 모른다.**
  ⭐ 우리는 이걸 **간발로 통과**했다 `[측정]` — 문서의 `npm run X` 105건 전량이 실재한다(플레이스홀더 1 외 0).
  그러나 **그건 우연이지 보장이 아니다**: 스크립트 이름이 바뀌면 105곳 중 어디가 깨지는지
  알 방법이 없다.
- ⓒ **대가**: 예제가 «실행 가능해야 한다»는 제약을 받아 **의사코드·부분 스니펫을 못 쓴다**.
  Rust 는 그 대가로 `ignore`·`no_run` 같은 도피구를 만들어야 했다.
- ⓓ **우리 현재: 없음** `[측정]`.
- ⓔ **최소형**: 문서에서 `npm run <X>` 를 정규식으로 뽑아 세 `package.json` 의 `scripts` 키와
  대조하는 **단언 하나**(오늘 메인이 돌린 스캔 그대로 · 20줄). 실행이 아니라 **존재만** 본다 —
  실행은 이 저장소 규모에 과하다.

### ③ **문서 검사가 CI 의 필수 관문이다** (Django `make check` = spelling + sphinx-lint + linkcheck + blacken-docs)

- ⓐ 「문서는 나중에」가 구조적으로 불가능해진다 — 머지 전에 통과해야 한다.
- ⓑ 없으면: 문서 수정이 **게이트를 한 번도 안 지나간다.**
  ⭐ 우리는 이게 **명시적으로 그렇다** `[측정]` — `.husky/pre-commit` 이 `grep -q '^web/'` 로
  스테이징을 거르므로 **`CLAUDE.md`·`web/docs/**`·`src-tauri/`·`.github/` 만 담긴 커밋은
  훅도 게이트도 통과하지 않는다**(주석이 _"문서만 커밋하면 통과"_ 라고 의도를 밝힌다).
  그 의도는 당시 옳았지만, 대가는 **문서가 이 저장소에서 유일하게 무검증인 층**이라는 것이다.
- ⓒ **대가**: 오타 한 줄 고치는 데 CI 를 태우게 된다. Django 는 `linkcheck` 가 «인터넷이 필요하고
  수 분 걸린다»고 스스로 적어 두고, 그래서 **`make check` 에서 분리**해 뒀다.
- ⓓ **우리 현재: 없음** `[측정]`.
- ⓔ **최소형**: ①②의 단언을 `vitest` 로 짓고 **`verify` 안에** 넣는다 — 그러면 CI 를 새로
  건드릴 필요가 없다(`build-test` 잡이 이미 `verify` 를 돈다). 단 훅은 `^web/` 조건 때문에
  문서 커밋에서 안 도므로, **훅 조건을 `^web/|^CLAUDE.md|^src-tauri/`** 로 넓히는 한 줄이 짝이다.

### ④ **뒤집힌 결정이 옛 자리에 부고로 남는다** (MADR `status: superseded by ADR-0123`)

- ⓐ 결정 기록의 가치는 «무엇을 정했나»가 아니라 **«지금도 유효한가»**다. 상태 필드가 없으면
  기록은 시간이 갈수록 **함정**이 된다.
- ⓑ 없으면: 인수인계받은 사람이 옛 항목을 읽고 **이미 뒤집힌 결정을 근거로 코드를 짠다.**
  ⚠ 우리 `결정로그.md` 는 **앞으로는 잘 표시한다**(「⚡ 전제가 무효화된 것」 절이 실재한다).
  없는 것은 **역방향**이다 — 41 항목 중 어느 것에도 «이 결정은 X 가 뒤집었다» 표식이 없다 `[읽음]`.
- ⓒ **대가**: 상태를 관리해야 한다. MADR 자신이 status 를 **선택 필드**로 두는 이유다.
- ⓓ **우리 현재: 부분** — 앞 방향만 있고 뒤 방향이 없다.
- ⓔ **최소형**: 새 항목이 옛 것을 뒤집을 때 **옛 항목 제목 옆에 한 줄**
  `> ⛔ 뒤집힘 → 2026-08-28 (2)`. 집행자는 필요 없다(41 항목 규모) — **`/실행` 의 닫기 절차에
  한 줄**을 넣는 것으로 족하다.

### ⑤ **결정·유예에 기계가 읽는 만료가 있다** (K8s `kep.yaml` 의 `status`·`latest-milestone`)

- ⓐ 「나중에」가 날짜를 갖지 않으면 그건 판단이 아니라 방치다.
- ⓓ **우리 현재: 있음(부분) — 그런데 형식이 넷으로 갈렸다** `[측정]`:
  `web/audit-allowlist.json`(사유+만료) · `server/audit-allowlist.json` · `e2e/a11y.spec.ts` 의
  `알려진위반`(현재 `{}`) · `scripts/freshness.mjs` 의 `보류`(현재 `{}`).
  그리고 **다섯째가 부모 저장소에 있다** — `../docs/유예_원장.md`(재검토일 2026-10-15·11-30).
  hub CI 는 부모를 체크아웃하지 않으므로 그 만료는 **hub 에서 도달 불가한 집행자**다.
- ⓔ **최소형**: 새 형식을 만들지 말고 **`freshness.mjs` 가 이미 가진 만료 판정**을 나머지 원장이
  재사용하게 한다(그 스크립트는 이미 «만료됐다» 와 «해소됐는데 안 지웠다» 양방향을 본다).
  ⛔ 부모 원장을 hub 으로 옮기라는 처방은 내지 않는다 — 부모의 판단이고, hub 은 사설 서브모듈이라
  CI 가 원리적으로 못 받는다(오버레이 §규약 축 이월 122~135줄이 그 근거를 이미 못박았다).
