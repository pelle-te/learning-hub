# `/리뷰 성능` — 러닝허브 1회차 (2026-08-27) · **기준선 회차**

## 1. 총평

**통과선**(_"사용자가 기다림을 인지하지 못하는가"_)은 **대체로 통과한다.** 그리고 그 사실이 이 회차의
결론이 아니다 — **이 저장소는 그 통과선을 재는 장치를 거의 안 갖고 있고, 갖고 있는 하나는 지금 빨갛다.**

수치부터: 실 셸(WebView2)에서 **앱 실행 → 첫 데이터가 중앙 881 ms** 다. 브라우저 프록시 p75 는
FCP 388 ms · LCP 464 ms · CLS 0 — CWV 목표의 4~7배 여유다. 상호작용은 관측된 최대 JS 처리가
**15.5 ms**(목표 200 ms). 규모를 50배(과목 100 · 오답 2,000)로 밀어도 부팅은 **평탄**하다.
즉 **체감 축에 고칠 것이 거의 없다** — 그 말이 곧 «이 축에 할 일이 없다»가 아니다.

이 회차의 무게는 전부 한 문장에 있다: ⭐ **재는 장치의 단위가 실물보다 굵다.** 오버레이 §1-B·§1-D 가
ux·코드 축에서 세운 명제인데, 성능 축에 대고 재니 **똑같이, 그리고 더 크게 참이었다**:

- 예산 다섯 축이 **`dist/assets` 안의 `.js`·`.css`·`.wasm`** 만 센다 → 폰 첫 방문 전송의 **56.6%**
  (2,009 KB 폰트)가 원리적으로 안 보인다. 심지어 «귀속 안 되는 산출물은 조용히 넘기지 않는다»는
  가드조차 그 폴더를 안 지난다.
- 예산이 **gzip 만** 센다 → 저엔트로피 페이로드를 342:1 로 접으면 **raw 7.10 MB** 가 다섯 축 전부를
  통과한다(실증 · exit 0).
- 시간 축 예산은 **하나**뿐인데, 그 하나가 **제품이 실제로 쓰지 않는 주소를 검사한다.**
- 부팅 계량이 「부팅」이라 부르는 구간은 실제 부팅의 **42%** 다(나머지 58%는 네이티브 기동).
- 회차 간 **보존이 0** 이다(`web/docs/성능/` 부재) — 「빨라졌다」를 말할 근거가 구조적으로 없다.

**범위와 그 밖.** 이 회차는 데스크톱 셸·폰 엔트리·서버 왕복·번들·게이트를 잰다.
**안 잰 것**: 실 Cloudflare 엣지 RTT · 사용자 실 데이터 분포(학습 표가 0행이라 시드는 **전량 합성**) ·
`P023` 이 남긴 히트맵 글로우 페인트 · prod 소스맵 부재로 인한 CPU 프로파일의 함수 단위 귀속.

```js
/* 축 ⑥ — 정적 자산(폰트·이미지·아이콘). ①②③은 매니페스트 그래프와 확장자 셋만 보므로
   첫 페인트 전송의 다수를 차지하는 폰트가 원리적으로 안 보인다(2026-08-27 실측: 폰 첫 방문
   3,549 KB 중 2,009 KB = 56.6%). ⚠ woff2·png 는 이미 압축이라 gz 가 아니라 **전송 바이트**다. */
const STATIC = { desktop: 2100, phone: 2100 }; // KB · 실측 2009 + 여유 ~5%
{
  const skip = /^(assets|\.vite|updates)\//;
  const files = [];
  const walk = (d) => {
    for (const e of readdirSync(d, { withFileTypes: true })) {
      const p = join(d, e.name),
        r = relative(dist, p).replace(/\\/g, '/');
      if (e.isDirectory()) {
        if (!skip.test(r + '/')) walk(p);
      } else if (!skip.test(r) && !/\.(html|js|css|webmanifest)$/.test(r))
        files.push({ r, kb: statSync(p).size / 1024 });
    }
  };
  walk(dist);
  const total = files.reduce((a, f) => a + f.kb, 0);
  for (const f of files.sort((a, b) => b.kb - a.kb)) console.log(`      ${f.kb.toFixed(1)}  ${f.r}`);
  const over = total > STATIC.desktop;
  if (over) failed = true;
  console.log(`${over ? 'OVER' : '  ok'}  static total ${total.toFixed(1)} / ${STATIC.desktop}`);
}
```

exit 1 을 본 뒤 원복.
