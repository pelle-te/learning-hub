## 메인이 서브에이전트와 다르게 판정한 것
- **osv-scanner 「20건」은 발견이 아니다.** 실제 컴파일되는 것은 **6패키지 6건**, 그중 **실취약 0**,
  상향 픽스 있는 것 **1건**(`event-listener`). 도구 출력을 그대로 실었다면 이 회차는 15건을
  거짓으로 올릴 뻔했다 — 커널 §"도구 출력은 발견이 아니다" 가 실제로 값을 낸 자리.
