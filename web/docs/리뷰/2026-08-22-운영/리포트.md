#### O001 · `web/scripts/release-verify.mjs:101-114` | `[측정]` | 비용 S

**서명 「키 신원」을 보는 축이 0개다.** 이 검사기는 «매니페스트의 `signature` == 로컬 `.sig`» 만 본다
(`:107` — `readFileSync(sigPath) === p.signature`). `tauri.conf.json` 의 `pubkey` 를 **한 번도 읽지 않는다**
(그 파일 전체에 `pubkey` 0건 — 실측).

**실패 시나리오**: 키를 재생성했거나 다른 기기/옛 백업의 키를 썼다 → `tauri:build` 통과(**어떤 유효한
minisign 키로도 서명된다**) → `release:stage` 통과(`signature` 가 비어 있지 않다) → `release:verify`
**통과**(로컬 `.sig` 와 서빙 값이 같다 — 둘 다 같은 잘못된 키에서 나왔으므로). 그런데 클라이언트가
대조하는 것은 배포본에 구워진 `pubkey` 다 → **전 사용자가 minisign 검증 실패.** 그리고 이 앱은
부팅 시 자동 확인을 안 하므로(`updater.rs` 설계) **사용자가 설정에서 누르기 전까지 아무도 모른다.**
C1(폴백 HTML)과 같은 «매니페스트는 살아 있는데 전달이 죽었다» 인데, C1 은 이 검사기가 잡고 이쪽은
잡는 축이 없다.

지금은 일치한다(실측: pub `keyId=e0def2444769d896` == sig `keyId=e0def2444769d896`).

**수정** — `:64`(버전 대조) 뒤에 축 하나. minisign 바이트 배치는 `[0..2]=알고리즘 · [2..10]=key id`:

```js
const keyIdOf = (b64) => {
  const line = Buffer.from(b64, 'base64').toString().trim().split('\n').pop().trim();
  return Buffer.from(line, 'base64').subarray(2, 10).toString('hex');
};
const want = keyIdOf(JSON.parse(readFileSync(CONF, 'utf8')).plugins.updater.pubkey);
for (const [platform, p] of Object.entries(local.platforms ?? {})) {
  const got = keyIdOf(Buffer.from(p.signature, 'base64').toString().split('\n')[1].trim());
  if (got !== want) {
    console.error(`❌ ${platform}: 서명 키 ${got} ≠ 배포본이 신뢰하는 키 ${want}`);
    console.error('   → 이대로 내면 **모든 클라이언트가 업데이트를 거부**한다.');
    process.exit(1);
  }
}
```

## 7. 유지 판정 — 도마에 올렸으나 옳았던 것

다음 회차가 같은 것을 다시 도마에 올리지 않게 남긴다.

- ⭐ **Cloudflare Workers + D1 의 비용 구조** — 무료 한도의 **0.02%~1.8%**. `pollMs` 를 주는 진입점이
  **0**(W24 은퇴)이라 **시간 비례 항이 없고**, `updated_at` 인덱스가 7개 동기화 테이블 전부에 있어
  읽는 행이 **변경 행 수에 비례하지 DB 크기에 비례하지 않는다**. 관측 테이블 넷은 `updated_at` 이
  없어 D1 에 도달조차 안 한다. **100배 성장까지 무료.** 이 축엔 지적 0건이고, 그건 설계의 성과다.
- **`updater.rs` 가 자동으로 확인·설치하지 않는 것** — 학습 세션 중 자기 재시작이 이 앱의 가장 나쁜
  실패 모드라는 근거가 머리주석에 있다. 「자동 확인이 없다」를 결함으로 읽지 마라.
- **`tauri:build`(15분)를 로컬 게이트에 둔 것** — CI 와 중복이지만 _"CI 엔 있는데 로컬엔 없다는 곧
  아무 데도 없다"_ 의 정면 적용이다. 비용 축에서 건드릴 자리가 아니다.
- **서버 레이트리미터 fail-open**(`index.ts:330`) — 주석이 _"여기서 지키는 것은 남용이지 기밀이
  아니다"_ 라 적었고 로컬 컷이 계속 돈다. 삼킴이지만 옳다.
- **SCA 원장 3개가 «비어 있는 채로 존재»하는 것** — 「아직 안 봤다」와 「보고 나서 비었다」를 구분하는
