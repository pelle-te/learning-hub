# 메타 — 2026-08-21 · ux 축 (팩 자신의 검증)

1. **팩이 시켰는데 못 한 것** — 「모든 상태를 실제로 띄워 본다」(`ux.md §축2`). dev 는 시드가
   없어 `blocked`·`execDb 실패`·`볼트 스캔 실패` 를 못 만들었다. **`지시가 모호함`**: 팩은
   _"화면을 안 열었으면 UX 지적은 전부 `[추측]`"_ 이라 말하는데, **시드가 없어 못 여는 상태**와
   **안 연 상태**를 구분하지 않는다. 전자는 `[읽음]`+검증법 병기가 맞다.
2. **팩이 안 시켰는데 해야 했던 것** — 시각 베이스라인을 **증거 소스로 읽기**. 88장은 앱을 안
   띄우고도 전 화면·양 테마·주요 상태를 보게 해 준다. 팩의 「도구」 절은 playwright/devtools MCP 만
   말하고 **저장소가 이미 가진 스냅샷**을 안 든다. 이번 회차 발견의 상당수(워드마크 4줄 붕괴 ·
   `HTTP 500` 노출 · 히트맵 색 단독)가 거기서 나왔다.
3. **거짓 양성을 유발한 지시** — 「§진보: 표본을 열어라」가 표본을 **제품 사이트**로 유도한다.
   Linear·Vercel 은 마케팅 페이지라 서드파티 CSS 가 섞여 `font-size` 고유값(27·79)이 부풀었다.
   **비교 가능했던 것은 「토큰 정의」층**(`--radius-4` · `--text-small-size`)이지 선언 총수가 아니다.
   총수만 봤으면 「Vercel 은 79종이니 우리 28은 양호」라는 정반대 결론이 나왔다.
4. **예산** — 흐름 68툴콜 / 지적 9 · 상태 83 / 지적 10 · 시각언어 79 / 지적 9 · a11y 93 / 지적 10.
   **네 축 다 살아 있다**(0건 하위축 없음). 메인은 §진보 표본 대조와 실물 측정에 집중했고,
   그 둘이 하위축이 못 낸 발견 셋(반픽셀 0 대조 · px/rem 역전 재현 · 320px 리플로우)을 냈다.
5. **표본 대조** — 했다. `curl` 로 CSS 를 실제로 받아 같은 정규식으로 셌다(원문 `스캔/원시값.md`).
   가장 값진 원시값은 개수가 아니라 **이름 짓는 법**이었다(값 vs 호출부).
