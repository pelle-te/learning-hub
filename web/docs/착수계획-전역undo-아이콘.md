## 2. 전역 ⌘Z — ✅ **출하 완료(2026-08-01)**

> 결과·게이트는 `로드맵.md#🅄-전역-z-출하`, 설계 결정은 `결정로그.md` 그날 첫 절이 SSOT.
> 아래 절차는 **이력으로** 남긴다. ⚠ 실행이 이 계획을 두 곳에서 정정했다:
> ① **2-3-①의 "`diffRowsDetailed` 를 고칠 필요가 없다"는 틀렸다** — `touched` 는 upsert 만 담아
> **삭제된 행을 못 살린다**(되돌리기가 가장 필요한 부류). pre-image 는 그 함수가 낸다.
> ② **2-3-⑦의 ⋯메뉴 은퇴를 안 했다** — ⌘Z 는 `loadState` 를 안 쌓으므로 지우면 "스냅샷 유지"
> 결정이 무효가 된다. 개명('스냅샷 복원')으로 대신했다.

### 2-1. 왜 위험한가 (읽고 시작해라)

되돌리기를 **병합 규칙**으로 태우는 설계라 `lib/cloud/merge.ts` 의 `applyPull` 인접을 건드린다.
이 저장소가 그 지점에서 낸 사고가 **넷**이고 **넷 다 출하 뒤 감사에서** 발견됐다:

- **C1** — 되살리기가 에코 억제표에 걸려 다른 기기에 영원히 안 감(`applyPull(batch, { echo })`)
- **C2** — 병합창 판정이 체인 **밖**이라 받아온 행을 되돌리는 문장이 만들어짐
- **H4** — 병합 쓰기가 flush 체인에 없어 낡은 메모리가 더 큰 스탬프로 덮음
- **H8** — 병합창 플래그가 불리언이라 중첩 시 안쪽 `finally` 가 바깥 창을 조기에 닫음

즉 **"동작한다"가 검증이 아니다.** 아래 2-4 의 테스트가 통과해야 착지다.

### 2-2. 이미 끝난 것 — 비용 실측(2026-07-31 · 로드맵 `#결정--전역-z-pre-image-비용-실측`)

핵심 셋만 옮긴다(수는 로드맵이 SSOT):

1. **접촉 행은 정확히 1이다** — 일반 편집 8종 전부 1행/1문장.
2. **pre-image 는 DB 읽기가 아니다** — `sqlite.ts` 의 `_last`(증분 diff 기준선)가 **이미 메모리에**
   있다. 로드맵의 _"쓰기 전에 한 번 더 읽으면 거의 공짜"_ 는 한 번 더 읽을 필요조차 없었다.
3. **진짜 비용 축은 바이트이고 편차가 670배다** — `week_alloc` 26B vs `settings.items` 17,353B.
   → **엔트리 수 상한은 메모리 상한이 아니다.** 사용자가 바이트 예산을 고른 이유가 이것이다.

### 2-3. 구현 순서 (각 단계가 독립적으로 녹색이어야 한다)

1. **`lib/db/undoStack.ts` 신설** — 순수 모듈. `push(preImage)` · `pop()` · 바이트 예산으로
   오래된 것부터 버림. **React·IPC 무관**(그래야 유닛 테스트가 전량 붙는다).
   - pre-image 는 `sqlite.ts` 의 `_last` 에서 접촉 키로 뽑는다. `diffRowsDetailed` 를 고칠
     필요가 없다 — `writeRows` 가 `_last` 와 `touched` 를 둘 다 손에 쥐고 있다.
   - "그 행이 없었다"(신규 생성)를 **표현할 수 있어야 한다** — 되돌리기가 삭제여야 하는 경우다.
2. **캡처 배선** — `writeRows` 성공 직후 push. ⚠ **병합 쓰기(`applyPull`)와 대량 쓰기
   (`loadState` 4곳)는 push 하지 않는다** — 전자는 내 편집이 아니고 후자는 `BACKUP_KEY` 몫이다
   (사용자 결정: 스냅샷 유지).
3. **되돌리기 적용** — `applyPull` 과 **같은 문장 모양**(툼스톤 가드 + `excluded.updated_at >`
   LWW). 재구현하지 말고 `merge.ts` 의 문장 생성을 함수로 뽑아 공유해라. 사본을 만들면 이
   문서가 경고한 넷과 같은 부류가 다섯 번째로 생긴다.
   - 스킵된 행은 **말한다**: _"3건 중 1건은 다른 기기가 지워 되돌리지 않았어요"_.
4. **메모리 반영** — DB 를 고쳤으니 `useApp` 이 다시 읽어야 한다. `applyMerged` 경로와 같은
   규율(빌린 pending 큐 되돌려놓기)을 지켜라.
5. **pull 이 오면 스택 무효화** — 로드맵이 남긴 3조건 중 하나. `applyPull` 성공 시 스택을 비운다
   (되돌릴 기준이 사라졌다).
6. **UI** — 전역 ⌘Z 등록(`shell/shortcuts.ts`). 그다음에야 아래 은퇴.
7. **은퇴** — `toastUndo` 호출부 **14곳**(실측 2026-08-01):
   `features/degree/Degree.tsx`×2 · `features/items/ChapterEditor.tsx` · `Items.tsx` ·
   `SkeletonPanel.tsx`×2 · `Subject.tsx` · `features/review/Review.tsx` ·
   `shell/actions.ts`×3(가져오기·초기화·캡처) + 팔레트 `act:undo` + ⋯메뉴.
   ⚠ `shell/actions.ts` 의 **가져오기·초기화 둘은 `undoLast`(스냅샷)** 라 남는다 — 사용자 결정.

### 2-4. 착지 조건 (로드맵이 든 3조건 + 실측이 더한 1)

- [ ] **pull 병합 시 스택 무효화 계약** — 테스트로 잠근다
- [ ] **역 recipe 왕복 속성 테스트** — `쓰기 → undo → 상태가 쓰기 전과 같다`
- [ ] **바이트 예산** — 상한을 넘기면 오래된 것부터 버리고, `settings.items` 한 건이 예산을
      통째로 먹는 경우가 테스트에 있어야 한다(17KB × N)
- [ ] **툼스톤 가드** — 다른 기기가 지운 행은 되살리지 않고 **그 사실을 말한다**

### 3-1. 실측 (2026-08-01 · 로드맵의 옛 수 `183개/57파일` 은 틀렸다)

**67종 · 234회 · 68파일.** 분포: features 143(파일-글리프) · lib 14 · app 12 · shell 6 ·
phone 4 · store 2 · components 1. 성격: **JSX 본문 ~150 · 문자열/라벨 ~37**.

### 3-2. 두 작업이다 (옛 계획은 ②를 안 셌다)

① **JSX 본문 → 아이콘 컴포넌트**(~150)

### 3-3. ⚠ 레이어 — 기존 `shell/icons.tsx` 를 그대로 쓸 수 없다

지금 `Icon` 은 `shell/icons.tsx` 에 있고 소비처가 **`app/` 셋뿐**이다(RailSidebar·SubTabs·TopBar).
그런데 교체 대상은 `features`·`components`·**`phone`** 에 걸쳐 있고, `components`·`phone` 은

`shell/icons.tsx` 는 탭 아이콘용 재수출만 남긴다. 옮기기 전에 이걸 결정하지 않으면 슬라이스
중간에 경계 린트가 터진다.

### 3-4. 슬라이스 — **개념 단위**(로드맵 개념표 14개)

한 슬라이스 = 한 개념 = **이식 → 실렌더 확인 → 스냅샷 재생성 → 커밋**. 개수가 많은 순:
`가져오기·저장` → `문서·노트` → `카드·복습` → `목표·집중` → `시간·일정` → `탐색·검색` →
`완료·성취` → `동기화·연결` → `지표·추세` → `AI·도구` → `경고·주의` → `재생·이동` → `정보` → `입력`.

⚠⚠ **`--update-snapshots` 를 먼저 돌리지 마라.** 이 저장소는 그것으로 두 번 물렸다(존재하지
않는 토큰이 회색으로 렌더 · 카드가 1글자 폭으로 붕괴 — **둘 다 정적 검사 전량 녹색**). 순서는
`이식 → 눈으로 확인 → 재생성` 이고, **재생성 대상은 "실패한 것"이 아니라 "그 UI 가 보이는 것 전부"**
다(임계 아래 드리프트가 조용히 통과한다 — §15-7 의 실증 세 번).

### 3-5. 마지막에 집행자를 세운다

전 슬라이스가 끝난 **뒤에** 이모지 금지 린트를 켠다(`no-restricted-syntax`). 먼저 켜면 234곳이
동시에 빨개져 슬라이스가 불가능해진다. 함께 넣을 것:

- **아이콘 이름 존재 검사** — `check:tokens` 와 같은 부류의 게이트. 없는 이름을 쓰면
  **아무것도 안 그려지고 게이트는 녹색**이 된다(정적 검사가 원리적으로 못 보는 자리).
- 예외 원장이 필요하면 **사유 + 만료일**을 함께 적는다(a11y·SCA 원장과 같은 규율).
